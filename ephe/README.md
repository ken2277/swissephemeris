# ephe フォルダについて

このフォルダは、**Swiss Ephemeris(スイス・エフェメリス)の天体暦データファイル**
(`.se1` という拡張子のファイルたち)を置くための場所です。

## そもそも「天体暦データ」って何?

星占い(ネイタルチャート)を作るには、
「〇〇年〇〇月〇〇日の、あの時刻に、太陽や月や惑星が
実際に宇宙のどの方向にあったか」という、とても正確な記録が必要です。

これは人間が計算するとものすごく大変な、複雑な天文学の計算ですが、
スイスの「Astrodienst(アストロダイエンスト)」という会社が、
NASAの精密な観測データをもとに計算し直して、
**無料で誰でも使えるデータファイル**として公開してくれています。
これが「Swiss Ephemeris」です。

## データファイルはなぜ Git に含めないの?

- 1ファイルが数MB~十数MBあり、複数使うとリポジトリ(GitHubの保管庫)が
  重くなってしまうため
- 誰でも同じ公式サイトから同じファイルをダウンロードできるため、
  わざわざコピーをGitHubに二重保存する必要がないため

そのため `.gitignore` でこのフォルダの中の `*.se1` ファイルは
記録されないようにしてあります(この README.md 自体は記録されます)。

## ダウンロードのしかた

プロジェクト直下にある `scripts/download_ephemeris.sh` を実行すると、
必要なファイルが自動的にこのフォルダにダウンロードされます。

```bash
bash scripts/download_ephemeris.sh
```

手動でのやり方や、なぜこのファイルが必要なのかの詳しい説明は
`docs/02_サーバー準備.md` に書いてあります。

## もしデータファイルが無いままアプリを動かしたら?

pyswisseph には「Moshier(モシエ)」という、データファイル無しでも
惑星の位置を計算できる簡易的な計算方法が内蔵されています。
そのため、このファイルが無くてもアプリ自体はエラーにならず動きます。

ただし Moshier は Swiss Ephemeris 本来の精度(ほぼ完璧な精度)より
わずかに精度が落ちる場合があるため、
**本番公開する前には、必ずこのファイルをダウンロードしておくことを
強くおすすめします。**
